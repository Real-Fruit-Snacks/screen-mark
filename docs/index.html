screen-mark

Free, open-source screenshot capture and annotation for Windows and Linux (X11), in pure Rust.

Ctrl+PrtSc saves and copies the monitor under your mouse. Ctrl+Shift+S opens an overlay like the one on this page: drag a region, draw on it, press Enter to copy.

screen-mark runs on a computer, not a phone. The button downloads the Windows installer; open this page on your PC to run it.

Download for Windows 1

v2.4.0 · 64-bit Windows 10 and 11 (tested on 11) · .msi installer, or the portable .zip · MIT licence Windows may warn about an unknown publisher: choose More info, then Run anyway. On Linux: the .tar.gz (X11 only, experimental) · build from source

Three hotkeys

CtrlPrtSc

Save and copy, in one press

Saves a PNG of the monitor under the mouse to Pictures\screen-mark and puts the same image on the clipboard. Presses made while one is still saving are queued, and file names never overwrite each other. Settings › Capture can switch it to all monitors.

CtrlShiftS

Open the overlay

Drag for a region, click for a window, Esc cancels. Enter or Ctrl+C copies the selection with everything drawn on it; Ctrl+S saves it as PNG, JPEG or WebP.

screen-mark lives in the tray, with optional autostart. The tray menu has the same captures, a delayed one with a 3, 5 or 10 second countdown, and two that open an image you already have, a file or the clipboard’s, in the same editor.

ShiftPrtSc

The last region, again

Captures the same area as your last region, with no overlay, then saves and copies it like Ctrl+PrtSc. A window or a chart you capture every day becomes one key.

screen-mark remembers the area across restarts. If it is on no screen any more, because a monitor was unplugged, a popup says so.

All three are rebindable in Settings › Keys. If another app already holds one (Greenshot, ShareX and some keyboard utilities register Ctrl+PrtSc or Shift+PrtSc), a popup names the key; click it to pick another.

Redact

Ctrl+Z and Ctrl+Shift+Z undo and redo, so nothing you draw is final until you copy. The scroll wheel changes the tool size. Highlight multiplies like a real highlighter, so dark text stays readable. Step markers number themselves.

Redact draws a solid box, and nothing under it reaches the copy. Pixelate only blurs, which is fine for a face in a crowd and not for a password. Rectangles, circles, lines and arrows can be an outline, dashed or filled: D switches. Hold Shift for squares, circles and lines at 15° steps. The arrow keys move the pointer, the region or the selected annotation one pixel at a time, ten with Shift, and a magnifier shows the pixels under the pointer while you place the region.

Every key is rebindable in Settings › Keys: click a binding and press the new combination. Settings refuses a combination another binding already uses, one Windows keeps for itself (Alt+Tab, Win+L), or a global hotkey another app has registered, and says which.

Dark and light modes, Nightshift and Dayshift from the RFS palettes. Five annotation colours, or any #rrggbb.

After the capture

Copy
Enter or Ctrl+C. The selection and everything drawn on it, ready to paste.
Save
Ctrl+S. A PNG, JPEG or WebP save dialog, or straight into your captures folder if you turn the dialog off.
Pin
Keeps the capture on screen as an always-on-top window, for reference while you work.
OCR
Runs the Windows OCR API on the capture and copies the text. Windows only, and the OCR language pack for your display language has to be installed.
Upload
Anonymous upload to Imgur. It ships with no client ID: register one at api.imgur.com and set it in Settings or SCREEN_MARK_IMGUR_CLIENT_ID.
Send
Hands the capture to a command of your own, an upload script or a copy to a share, and copies what it prints.
History
The last 20 captures, in their own window: copy one again, save it, delete it, or mark it up again with its arrows and text still editable.

Two switches in Settings › Capture change the region flow. Save a file every time I copy writes a PNG alongside each copy. Copy as soon as a region is drawn skips the toolbar, so drag and release is the whole job.

Why it exists

I wanted a screenshot tool that starts in under a second, draws an arrow without a round trip through a web view, and leaves no background service I didn’t ask for.

This is that: winit for windows, tiny-skia for drawing, a tray icon, three global hotkeys and a TOML file. The release is one exe with no browser engine inside.

Install

  1. Download the installer and run it. It installs for your user only, so it doesn’t ask for admin rights.
  2. Open screen-mark from the Start menu. It starts in the tray, by the clock; Windows may tuck the icon under the ^ arrow there.
  3. Press Ctrl+PrtSc to save and copy a screen, or Ctrl+Shift+S to open the overlay.
  • Windows 10 and 11

    Download the installer

    screen-mark-v2.4.0-windows-x64.msi, with a Start menu entry. A 1.x MSI is upgraded in place.

    screen-mark-v2.4.0-windows-x64.zip

    Portable. The exe asks before it installs itself to AppData.

    Neither is code-signed yet, so Windows SmartScreen may stop the first run: choose More info, then Run anyway.

  • Linux

    screen-mark-v2.4.0-linux-x64.tar.gz

    X11, or Wayland through the desktop’s screenshot portal; experimental. Built on Ubuntu 24.04; it needs GTK 3, libxdo, libxkbcommon-x11 and an AppIndicator library for the tray (on Ubuntu, sudo apt install libxdo3 libxkbcommon-x11-0 libayatana-appindicator3-1). Extract, chmod +x screen-mark, run it: it starts in the tray, with the same hotkeys.

The latest release lists every file with its SHA-256 checksum, also in SHA256SUMS.txt.

Or build it from source with Rust 1.88 or later:

cargo install --git https://github.com/Real-Fruit-Snacks/screen-mark --locked

No internet where you build? The release’s source-vendored.tar.gz holds every dependency and builds with cargo build --offline. The README lists the tools to bring.

From the command line

screen-mark
Starts in the tray.
screen-mark capture --clipboard
Captures the full screen to the clipboard, no UI.
screen-mark capture --save out.png
Captures the full screen to a file, no UI.
screen-mark capture --delay 5
Counts down five seconds on screen, then opens the overlay.
screen-mark edit photo.png
Opens an image to mark up; with no file, the clipboard’s image.
screen-mark install
Copies the exe to AppData with a Start Menu entry and PATH. uninstall removes it.

Settings are written on first run to %APPDATA%\screen-mark\config.toml on Windows or ~/.config/screen-mark/config.toml on Linux. Every key is optional; the README lists them.

Tested on

  • Windows 11, Rust stable. My daily machine; every release is used in anger before it’s tagged.
  • Windows Server 2025, Rust stable. CI builds, tests and runs clippy on every push.
  • Ubuntu 24.04 on X11, Rust stable. CI builds and tests, then drives the real binary on a virtual display with two monitors.
  • Wayland: capture goes through the screenshot portal, tested on CI against a stand-in, not yet on a real GNOME or KDE session.
  • Not tested: Windows 10, which it supports but I don’t run; and macOS, where it doesn’t build.

Known issues

  • Linux capture is experimental. Multi-monitor and HiDPI aren’t verified there. Wayland has no global hotkeys: bind a desktop shortcut to screen-mark capture.
  • OCR is Windows only and needs the OCR language pack for your display language.
  • Imgur upload needs your own client ID.
  • Window capture skips cloaked UWP windows on purpose, so some Store apps can’t be picked by click.
  • Ctrl+PrtSc and Shift+PrtSc are taken on some machines. screen-mark says so and lets you pick another key.
  • Linux: capture --clipboard loses the image when the command exits, because X11 clipboards live in the owning process. The tray app’s clipboard is fine.
  • Upgrading from HydroShot 1.x (screen-mark’s old name) moves your config, history and autostart across. Run hydroshot uninstall once to remove an old self-installed copy.
